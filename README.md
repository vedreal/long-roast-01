A three-day contest for the best single satirical sentence about lawmakers who regulate AI, crypto or the internet but cannot convert a file to PDF. This entry scores ten fresh one-sentence roasts against the judge's published criteria — on-subject, real turn, aim on lawmakers, quotable with the punch last, specific unexpected detail — and writes the winner to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program prints the ranked candidates, then writes the winning sentence to `/output/entry.txt` (UTF-8, 1–320 characters, a single sentence).
